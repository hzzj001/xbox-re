书源设置

怎么用

内置书源开箱可用。也可以把「阅读」App 的书源 JSON 粘进来，自动识别 CSS 规则。

支持的书源规则
  • @css:选择器@text / @html / @href / @src / @title
  • 列表选择器 + 书名 / 作者 / 链接 / 封面 / 简介 / 最新章节
  • ##正则##替换 做文本清洗，可用 || 取首个非空
  • 搜索模板支持 {{key}} {{page}}，GET/POST 都行

识别不了的书源会标红，可以手动改规则再保存。
